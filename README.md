 🛒 E-Commerce App

A modern Flutter e-commerce application developed to practice building scalable mobile applications using Flutter.

The project follows a feature-based architecture and focuses on creating a clean and responsive shopping experience.

> 🚧Project Status: Currently under development.



 ✨ Current Features

✅ User Login

✅ Product Listing

✅ Product Details

✅ Shopping Cart

✅ Wishlist

✅ Dark Theme

✅ Responsive UI



 🚧 Planned Features

- Firebase Authentication
- Product Search
- Backend Integration
- Online Payment
- Order History
- Push Notifications
- User Reviews



 🛠 Tech Stack

- Flutter
- Dart
- GetX
- Get Storage



 📂 Project Structure


lib/
├── bindings/
├── common/
├── data/
├── features/

This project follows a feature-based architecture to improve scalability and maintainability.
